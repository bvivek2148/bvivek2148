## 🚀 Featured Projects

### 🛡️ WebGuard

**Intelligent Web Application Firewall with ML-Based Threat Detection**

A security-focused WAF designed to detect, analyze, and respond to malicious web traffic in real time.

* Inspects incoming HTTP requests for suspicious and malicious patterns
* Uses **TF-IDF + Logistic Regression** for ML-based threat classification
* Implements **dynamic IP blacklisting** for automated response
* Provides a real-time threat intelligence and security monitoring dashboard
* Uses **WebSockets** for live security-event streaming
* Stores security events and request data using **SQLite**
* Follows **OWASP-oriented web application security principles**

**Tech:** React • FastAPI • Python • Machine Learning • SQLite • WebSockets • Docker

---

### 🔐 Ransom-Trap

**Entropy-Based Ransomware Detection & Deception System**

A dual-layer endpoint security solution combining ransomware detection with deception techniques.

* Uses **Shannon Entropy** to identify abnormal file-encryption behavior
* Uses **honeytoken/deception files** to detect suspicious activity
* Combines behavioral detection with deception-based detection
* Designed to provide an additional security layer against ransomware activity
* Includes a Flask-based interface for monitoring and analysis

**Tech:** Python • Flask • Shannon Entropy • Cybersecurity • Deception Technology
